# Проект аналитики и проектирования системы внутрибанковских переводов

Это учебный проект по созданию аналитического документа системы внутрибанковских переводов в целях добавления в портфолио и демонстрации навыков системного аналитика. Данный сервис позволяет клиенту осуществлять переводы между своими счетами или на счет другого клиента и получать историю переводов и их статус.
## Границы проекта
**Входит:**
- создание перевода
- проверки
	- существование и статус счетов
	- достаточность средств
	- дневной лимит
- получение статуса перевода
- история переводов клиента

**Не входит:**
- СБП
- межбанковские и валютные переводы
- переводы по номеру карты
- комиссии
- реальный антифрод (только как внешняя система)

## Структура репозитория
- README.md - описание проекта
- docs/01-context.md - цель, участники, границы, глоссарий
- docs/02-requirements.md - пользовательские истории, критерии приемки, бизнес-правила и нефункциональные требования
- diagrams/ (исходники .bpmn, .puml и картинки .png) - UML, BPMN, ER диаграммы
- db/schema.sql - создание таблиц
- db/test-data.sql - вымышленные данные для теста запросов
- db/queries.sql - примеры запросов
- api/openapi.yaml - спецификация API между мобильным приложением и системой переводов: методы, запросы и ответы, ошибки
